# React + Vite Todo App

A modern, feature-rich Todo application built with React, Vite, and CSS. It includes local storage persistence, task filtering, and a clean user interface.

## Features

- **Add & Delete Tasks:** Easily create new tasks and remove them when finished.
- **Toggle Completion:** Click on any task to mark it as complete or active.
- **Local Storage Persistence:** Your tasks are automatically saved to your browser's local storage so you don't lose them on refresh.
- **Filter Tasks:** Switch between **All**, **Active**, and **Completed** views.
- **Live Counter:** See a real-time count of how many items are left to complete.

## Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation & Running

1. Clone the repository or open the project folder in your terminal.
2. Install dependencies:
   ```bash
   npm install
   npm run dev```
