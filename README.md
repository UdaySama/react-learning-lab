# React Learning Lab ⚛️

A hands-on React.js learning repository focused on building a strong foundation in modern React and frontend development through structured practice and small projects.

## 🎯 Goals

* Build a strong understanding of React fundamentals
* Practice writing reusable and maintainable components
* Understand React Hooks and state management
* Work with REST APIs and asynchronous data
* Learn client-side routing
* Build and validate forms
* Improve JavaScript skills through React development
* Practice Git and GitHub workflow
* Gradually build production-oriented frontend projects

## 🛠️ Technologies

* React.js
* Vite
* JavaScript (ES6+)
* HTML5
* CSS3
* REST APIs
* Git & GitHub
